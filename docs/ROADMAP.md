# Study execution roadmap

| Stage | Implemented work and intended evidence | Completion record |
|---|---|---|
| A Acquisition and audit | Versioned public manifests, checksums, sample/run crosswalk, explicit 2021 ant brain cohort, safe extraction, chronological tracking/control identities | Source manifest, acquisition receipts and schema audit |
| B Source replication and pilot | Two ant libraries, two fly experiments, two agent seeds; reproduce designated source summaries; measure time, RAM, storage expansion and throughput | Source replication and benchmark receipts |
| C Behavioural discovery | Duration-aware Student-t state models, gain/transition/direction alternatives, parameter recovery, grouped nested validation, mantis choice and censoring models | Recovery diagnostics, model comparison and frozen configuration |
| D Independent interventions | Calibration separated from evaluation, matched controls, family holdouts, movement-entry/persistence/speed decomposition, survival sensitivity | Withheld component predictions and contrast covariance |
| E Molecular transfer | Strand-aware ant counts, separate mantis integer counts, DESeq2 phase contrasts, orthology, frozen reversible score, refusal challenge, grouped external gene prediction | Count/design checks, frozen score and external predictions |
| F Computational experiments | Matched recurrent architectures and feedforward baseline, separate development/final seeds, frozen perturbations, norm and policy-divergence matching, restoration and held-out transfer | Training/checkpoint provenance, competence probes and per-seed outcomes |
| G Synthesis and release | Independent-unit uncertainty, declared multiplicity families, six evidence-based figures, claim-to-result index, durable archive | Inference records, inspected figures and release manifest |

The initial finite Slurm plan queues native Python/CUDA/R qualification, source verification/audit, two ant brains, two fly experiments, two agent seeds, a separate CPU evaluation benchmark and a bounded primary orthology benchmark. Biological and reference files download directly to Narval in independent provider groups. Full scientific phases use new finite plans after their actual sources and measured runtime/storage requirements are available. Eligible phases can be submitted automatically by the scheduled assessment.

The independent intervention and gene-transfer stages require original animal, reagent, gene, control and family crosswalks. A pooled summit matrix cannot supply those identities. The native archive audit records which comparisons are supported and which annotations remain missing. No missing intervention metadata or neural perturbation sign is filled by guessing.

Negative or underdetermined scientific results remain valid outcomes. Pipeline stages never substitute simulated animals for biological replication or merge different source representations into additional subjects.
